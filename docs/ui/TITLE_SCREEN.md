# Title screen

The default title screen ("Vanta") is painted by `gui/title/VantaTitleUi` over the live lobby world
(`gui/lobby`). It reuses vanilla's Realms, Options and Quit buttons, so their
actions are unchanged; the widgets draw nothing and the labels are painted in Poppins.

- Top bar: Vanta mark and wordmark, centred tabs (Play, Realms, Options), then Discord invite,
  notification history, Mod Menu (disabled when it is not installed), the Vanta menu, the menu-style
  dropdown and a quit button.
- Bottom left: account card, FPS / frame time card and quiet links (Share, Language, Accessibility, Credits,
  plus any buttons other mods add to the title screen).
- Bottom right: the play card. Singleplayer launches the most recently played world, Multiplayer joins the
  last used server (live status and ping through `ServerStatusPinger`); the Recent tiles select another
  entry and "All" opens the vanilla list screen.
- Styles (`VantaClientPreferences.titleStyle`): `LOBBY` (Vanta), `CLASSIC` (Vanta v1, the previous
  layout) and `VANILLA`. The dropdown and Settings > Preferences > Title screen change it.
- Notifications: `VantaNotificationManager` keeps the 40 most recent notifications for the bell panel.

Textures are generated by `tools/title-assets/generate.py` (icons are white so they can be tinted).
Layout uses one scale unit derived from the screen height; every size is a multiple of it.

The lobby world is ticked each client tick (`VantaLobbyWorld.tick`); without that its sky, light and
environment state stay uninitialised and the frame renders black.
